## 🚀 What's New in v0.1.2

### Highlights
This release is a security and CI hardening patch for `counter-service`. Several transitive dependency vulnerabilities (including `brace-expansion`, `tar`, and `sigstore`) have been remediated by pinning overrides and upgrading `npm` in the Docker runtime stage. The CI pipeline has also been stabilised with fixes to Trivy container scanning, optional secret scanning, and a devbox action upgrade.

### 🔒 Security
- Pinned `brace-expansion` to `>=5.0.8` via `overrides` to remediate known CVE in transitive dependency tree.
- Upgraded `npm` in the Docker runtime stage to eliminate bundled CVEs affecting `tar`, `brace-expansion`, and `sigstore`.
- Added `.trivyignore` to suppress accepted/false-positive findings and prevent noise in container scan reports.

### 🐛 Bug Fixes
- Fixed Trivy container scan `image-ref` to correctly reference the `:main` tag during CI scans.
- Made Gitleaks secret scanning optional (graceful skip on Linux CI environments where it is unavailable).
- Upgraded `devbox-install-action` to `v0.13.0` to resolve Nix lock file permission errors in CI.
